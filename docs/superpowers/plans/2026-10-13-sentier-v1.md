# Sentier v1 : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** construire l'addon WoW Sentier (moteur de guides + guides de réputation de Midnight) et ses outils Python (catalogue des quêtes, import de la collecte).

**Architecture :** addon Lua découpé en `Core/` (registre des guides, état, resets, sauvegarde, modèles d'affichage, collecte, événements), `Sensors/` (seul accès aux API de quêtes et de réputation du jeu), `Navigation/` (TomTom ou repère du jeu), `UI/` (une fenêtre, onglets Étape/Liste, réglages) et `Guides/` (données). La logique est en fonctions pures testées hors du jeu avec busted, en simulant `Sensors`. Les outils Python n'utilisent que la bibliothèque standard.

**Tech Stack :** Lua 5.1 (WoW 12.1, `## Interface: 120100`), busted (tests Lua, exécutés avec le Lua 5.4 de Homebrew), Python 3.9 + pytest, API web Blizzard Game Data.

**Spec :** `docs/superpowers/specs/2026-10-13-sentier-design.md`

## Global Constraints

- Code Lua compatible 5.1 (WoW) : pas de `goto`, pas de `//`, pas de bibliothèque `utf8`, pas de `table.unpack`, pas d'opérateurs binaires 5.3.
- `## Interface: 120100` dans le `.toc`.
- Tous les textes affichés au joueur sont dans `Sentier/Locales/fr.lua` (`ns.L`), nulle part ailleurs.
- Seul `Sentier/Sensors/Sensors.lua` appelle `C_QuestLog`, `C_MajorFactions`, `C_TaskQuest`, `C_DateAndTime`, `C_QuestOffer`, `HaveQuestRewardData` et `C_Map.GetMapInfo` / `GetBestMapForUnit` / `GetPlayerMapPosition`. `Navigation` seul appelle `TomTom`, `C_Map.SetUserWaypoint`, `C_Map.ClearUserWaypoint`, `UiMapPoint`, `C_SuperTrack`. `UI/` n'appelle aucune de ces API.
- L'addon ne doit jamais lever d'erreur Lua à cause des données : les erreurs de lecture deviennent `nil` + un message dans `ns.Registry.problems` (affiché par `/sentier debug`).
- Aucun contenu repris de Zygor.
- Python : bibliothèque standard uniquement (pytest seulement pour les tests), compatible 3.9 (pas de `match`, pas de `X | Y` dans les annotations).
- `.env` (identifiants Blizzard) ne doit jamais être commité.
- Identifiants des factions de Midnight (relevés dans l'API Blizzard le 2026-10-13) : Tribu des Amani 2696, La Singularité 2699, Hara’ti 2704, Cour de Lune-d’Argent 2710, Forces de Zul’jarra 2772.

## Review Focus

1. Une fonction du jeu absente ou renommée par un patch (par exemple `C_TaskQuest.GetQuestsOnMap`) : le capteur renvoie `nil`, la tâche passe en « inconnu », un problème est noté, aucune erreur Lua. Test : `tests/lua/sensors_spec.lua` (Task 3).
2. Les récompenses d'une quête mondiale ne sont pas encore chargées à la connexion : Sentier demande leur chargement puis se recalcule sur `QUEST_DATA_LOAD_RESULT`. Test : `sensors_spec.lua` (Task 3) ; événement enregistré dans `Core.lua` (Task 11).
3. Le guide mémorisé pour le personnage n'existe plus (renommé ou supprimé) : Sentier retombe sur le premier guide. Test : `registry_spec.lua` (Task 1).
4. Toutes les sources sont coupées, ou tout est fait : l'onglet Étape affiche « Rien à faire pour l'instant. » sans erreur. Tests : `state_spec.lua` (Task 4) et `models_spec.lua` (Task 5).
5. Une coche manuelle posée juste avant le reset hebdomadaire disparaît après, alors qu'une coche sur une tâche unique reste. Une coche « partagée » vaut pour tous les guides. Tests : `db_spec.lua` (Task 2) et `state_spec.lua` (Task 4).

```lua
function H.fakeSensors()
  local f = {
    now = 1000000,
    weeklyStart = 900000,
    dailyUntil = 3600,
    done = {},
    renown = {},
    worldQuests = {},
    objectives = {},
    position = nil,
  }
  f.Now = function() return f.now end
  f.IsQuestDone = function(id)
    local v = f.done[id]
    if v == "error" then return nil end
    return v == true
  end
  f.GetRenown = function(faction) return f.renown[faction] end
  f.GetActiveWorldQuests = function(faction) return f.worldQuests[faction] end
  f.FindZoneMaps = function() return {} end
  f.GetWeeklyResetStart = function() return f.weeklyStart end
  f.GetSecondsUntilDailyReset = function() return f.dailyUntil end
  f.GetObjectiveProgress = function(questId) return f.objectives[questId] end
  f.GetPlayerPosition = function() return f.position end
  return f
end

function H.load(saved)
  saved = saved or {}
  _G.Sentier = nil
  _G.SentierDB = saved.account
  _G.SentierCharDB = saved.char
  local ns = {}
  for _, path in ipairs(H.FILES) do
    if exists(path) then assert(loadfile(path))("Sentier", ns) end
  end
  ns.Sensors = H.fakeSensors()
  if ns.DB then ns.DB:Init() end
  return ns
end

function H.hasProblem(ns, needle)
  for _, p in ipairs(ns.Registry.problems) do
    if p:find(needle, 1, true) then return true end
  end
  return false
end

return H
```

`Sentier/Core/Registry.lua` :

```lua
local _, ns = ...
local L = ns.L

local Registry = { guides = {}, problems = {}, seen = {} }
ns.Registry = Registry

ns.SOURCES = { "sidequests", "weekly", "daily", "rares", "worldquests" }

function Registry:Problem(message)
  if self.seen[message] then return end
  self.seen[message] = true
  self.problems[#self.problems + 1] = message
end

local Guide = {}
Guide.__index = Guide

function Registry:NewGuide(id, opts)
  assert(type(id) == "string" and opts and opts.title and opts.category, "NewGuide(id, { title, category })")
  if self.guides[id] then self:Problem("Guide en double : " .. id) end
  local guide = setmetatable({
    id = id,
    title = opts.title,
    category = opts.category,
    faction = opts.faction,
    catalog = opts.catalog or {},
    tasks = {},
    byId = {},
    order = {},
  }, Guide)
  self.guides[id] = guide
  return guide
end

function Registry:Get(id)
  return self.guides[id]
end

function Registry:List()
  local list = {}
  for _, guide in pairs(self.guides) do list[#list + 1] = guide end
  table.sort(list, function(a, b)
    if a.category ~= b.category then return a.category < b.category end
    return a.title < b.title
  end)
  return list
end

function Registry:Resolve(id)
  return (id and self.guides[id]) or self:List()[1]
end

local function merge(base, opts)
  for k, v in pairs(opts or {}) do base[k] = v end
  return base
end

function Guide:Add(task)
  task.key = tostring(task.id)
  if self.byId[task.key] then
    Registry:Problem(("Tâche en double dans %s : %s"):format(self.id, task.key))
    return self.byId[task.key]
  end
  task.factions = task.factions or (self.faction and { self.faction }) or {}
  task.requires = task.requires or {}
  self.tasks[#self.tasks + 1] = task
  self.byId[task.key] = task
  return task
end

function Guide:Quest(questId, opts)
  local task = merge({ id = questId, type = "quest", source = "sidequests", reset = "none", questIds = { questId } }, opts)
  local info = self.catalog[questId]
  if info then
    task.title = task.title or info.title
    task.zone = task.zone or info.zone
  end
  if not task.title then
    Registry:Problem(("Quête absente du catalogue : %d (%s)"):format(questId, self.id))
  end
  return self:Add(task)
end

function Guide:Weekly(id, opts)
  return self:Add(merge({ id = id, type = "weekly", source = "weekly", reset = "weekly" }, opts))
end

function Guide:Daily(id, opts)
  return self:Add(merge({ id = id, type = "daily", source = "daily", reset = "daily" }, opts))
end

function Guide:Rare(id, opts)
  local task = merge({ id = id, type = "rare", source = "rares", reset = "daily" }, opts)
  task.questIds = task.questIds or (task.questId and { task.questId }) or nil
  return self:Add(task)
end

function Guide:WorldQuests(opts)
  return self:Add(merge({ id = "worldquests", type = "worldquests", source = "worldquests", reset = "none", title = L.GROUP_WORLDQUESTS }, opts))
end

function Guide:Order(list)
  self.order = {}
  for _, id in ipairs(list) do
    local task = self.byId[tostring(id)]
    if task then
      self.order[#self.order + 1] = task
    else
      Registry:Problem(("Ordre de %s : tâche inconnue %s"):format(self.id, tostring(id)))
    end
  end
end

Sentier = Sentier or {}
function Sentier:NewGuide(id, opts)
  return Registry:NewGuide(id, opts)
end
```

```lua
local H = dofile("tests/lua/helper.lua")

describe("Reset", function()
  local ns
```

```lua
local Reset = {}

local DAY = 86400

-- Date (secondes Unix) du dernier reset de ce type, ou nil si inconnue ou sans objet.
function Reset:LastReset(kind)
  local S = ns.Sensors
  if kind == "weekly" then return S.GetWeeklyResetStart() end
  if kind == "daily" then
    local untilNext = S.GetSecondsUntilDailyReset()
    if not untilNext then return nil end
    return S.Now() + untilNext - DAY
  end
  return nil
end

function Reset:IsStale(stamp, kind)
  local last = self:LastReset(kind)
  return last ~= nil and stamp < last
```

```lua
local ACCOUNT_DEFAULTS = {

  marks = {},
  skips = {},

local function fill(target, defaults)
  for k, v in pairs(defaults) do
    if type(v) == "table" then
      if type(target[k]) ~= "table" then target[k] = {} end
      fill(target[k], v)
    elseif target[k] == nil then
      target[k] = v
    end
  end
  return target
end

function DB:Init()
  SentierDB = fill(type(SentierDB) == "table" and SentierDB or {}, ACCOUNT_DEFAULTS)
  SentierCharDB = fill(type(SentierCharDB) == "table" and SentierCharDB or {}, CHAR_DEFAULTS)
  self.account, self.char = SentierDB, SentierCharDB
end

-- Une tâche « shared » a la même coche dans tous les guides (ex. gouffres généreux).
local function key(guide, task)
  return (task.shared and "shared" or guide.id) .. ":" .. task.key
end

function DB:IsMarked(guide, task) return self.char.marks[key(guide, task)] ~= nil end
function DB:SetMarked(guide, task, on) self.char.marks[key(guide, task)] = on and ns.Sensors.Now() or nil end
function DB:IsSkipped(guide, task) return self.char.skips[key(guide, task)] ~= nil end
function DB:SetSkipped(guide, task, on) self.char.skips[key(guide, task)] = on and ns.Sensors.Now() or nil end

function DB:ClearSkips(guide)
  for _, task in ipairs(guide.tasks) do self.char.skips[key(guide, task)] = nil end
end

function DB:Prune(guide)
  for _, task in ipairs(guide.tasks) do
    local k = key(guide, task)
    for _, store in ipairs({ self.char.marks, self.char.skips }) do
      local stamp = store[k]
      if stamp and ns.Reset:IsStale(stamp, task.reset) then store[k] = nil end
    end
  end
```

```lua
local _, ns = ...
local L = ns.L

-- Seul fichier qui lit les quêtes, la réputation et les resets dans le jeu.
-- Chaque lecture est protégée : en cas d'erreur, elle renvoie nil et note un problème.
local S = {}
ns.Sensors = S

local function safe(label, fn, ...)
  local ok, result = pcall(fn, ...)
  if ok then return result end
  ns.Registry:Problem(("Lecture impossible (%s) : %s"):format(label, tostring(result)))
  return nil
end

local function normalize(rewards)
  local out = {}
  for _, r in ipairs(rewards or {}) do
    if r.factionID and r.rewardAmount then out[#out + 1] = { factionId = r.factionID, amount = r.rewardAmount } end
  end
  return out
end

function S.Now()
  return time()
end

function S.IsQuestDone(questId)
  return safe("quête", function() return C_QuestLog.IsQuestFlaggedCompleted(questId) == true end)
end

function S.GetObjectiveProgress(questId, index)
  return safe("objectif", function()
    local objectives = C_QuestLog.GetQuestObjectives(questId)
    local o = objectives and objectives[index or 1]
    if not o or not o.numRequired or o.numRequired == 0 then return nil end
    return { have = o.numFulfilled or 0, need = o.numRequired }
  end)
end

function S.GetRenown(factionId)
  return safe("renom", function()
    local d = C_MajorFactions.GetMajorFactionData(factionId)
    if not d then return nil end
    return { level = d.renownLevel or 0, earned = d.renownReputationEarned or 0, threshold = d.renownLevelThreshold or 0, name = d.name }
  end)
end

function S.GetActiveWorldQuests(factionId, mapIds)
  return safe("quêtes mondiales", function()
    local getQuests = C_TaskQuest.GetQuestsOnMap or C_TaskQuest.GetQuestsForPlayerByMapID
    local list, seen = {}, {}
    for _, mapId in ipairs(mapIds) do
      for _, q in ipairs(getQuests(mapId) or {}) do
        local id = q.questID or q.questId
        if id and not seen[id] and C_QuestLog.IsWorldQuest(id) then
          seen[id] = true
          local amount = 0
          for _, r in ipairs(normalize(C_QuestLog.GetQuestLogMajorFactionReputationRewards(id))) do
            if r.factionId == factionId then amount = r.amount end
          end
          if amount > 0 then
            list[#list + 1] = {
              questId = id,
              title = C_TaskQuest.GetQuestInfoByQuestID(id) or L.UNKNOWN_QUEST:format(id),
              rep = amount,
              map = q.mapID or mapId,
              x = q.x and q.x * 100,
              y = q.y and q.y * 100,
            }
          elseif not HaveQuestRewardData(id) then
            C_TaskQuest.RequestPreloadRewardData(id)
          end
        end
      end
    end
    table.sort(list, function(a, b)
      if a.rep ~= b.rep then return a.rep > b.rep end
      return a.questId < b.questId
    end)
    return list
  end)
end

local function normName(name)
  return ((name or ""):gsub("’", "'")):lower()
end

local mapCache = {}

-- Les numéros de carte de Midnight ne sont pas documentés : on les retrouve par leur nom.
function S.FindZoneMaps(names)
  local cacheKey = table.concat(names, "|")
  if mapCache[cacheKey] then return mapCache[cacheKey] end
  local found = safe("cartes", function()
    local wanted = {}
    for _, n in ipairs(names) do wanted[normName(n)] = true end
    local list = {}
    for id = 2300, 2700 do
      local info = C_Map.GetMapInfo(id)
      if info and wanted[normName(info.name)] then list[#list + 1] = id end
    end
    return list
  end)
  mapCache[cacheKey] = found
  return found
end

function S.GetQuestRepRewards(questId)
  return safe("réputation", function() return normalize(C_QuestLog.GetQuestLogMajorFactionReputationRewards(questId)) end)
end

function S.GetOfferedQuestRepRewards()
  return safe("réputation proposée", function() return normalize(C_QuestOffer.GetQuestOfferMajorFactionReputationRewards()) end)
end

function S.GetQuestTitle(questId)
  return safe("titre", function() return C_QuestLog.GetTitleForQuestID(questId) end)
end

function S.GetPlayerPosition()
  return safe("position", function()
    local map = C_Map.GetBestMapForUnit("player")
    if not map then return nil end
    local pos = C_Map.GetPlayerMapPosition(map, "player")
    if not pos then return nil end
    local x, y = pos:GetXY()
    return { map = map, x = math.floor(x * 1000 + 0.5) / 10, y = math.floor(y * 1000 + 0.5) / 10 }
  end)
end

function S.GetWeeklyResetStart()
  return safe("reset hebdomadaire", function() return C_DateAndTime.GetWeeklyResetStartTime() end)
end

function S.GetSecondsUntilDailyReset()
  return safe("reset journalier", function() return C_DateAndTime.GetSecondsUntilDailyReset() end)
end
```

```lua
local L = ns.L

local State = {}
ns.State = State

-- true si toutes les quêtes sont faites, false si l'une ne l'est pas, nil si l'une est illisible.
local function allDone(questIds)
  for _, id in ipairs(questIds) do
    local done = ns.Sensors.IsQuestDone(id)
    if done == nil then return nil end
    if not done then return false end
  end
  return true
end

-- nil si les prérequis sont remplis, sinon le statut ("locked" ou "unknown") et la raison.
local function checkRequires(task)
  for _, req in ipairs(task.requires) do
    if req.renown then
      local renown = task.factions[1] and ns.Sensors.GetRenown(task.factions[1])
      if not renown then return "unknown" end
      if renown.level < req.renown then return "locked", L.REQUIRES_RENOWN:format(req.renown) end
    elseif req.quest then
      local done = ns.Sensors.IsQuestDone(req.quest)
      if done == nil then return "unknown" end
      if not done then return "locked", L.REQUIRES_QUEST:format(req.title or L.UNKNOWN_QUEST:format(req.quest)) end
    end
  end
  return nil
end

function State:TaskStatus(guide, task)
  local info = {}

  if task.type == "worldquests" then
    local maps = ns.Sensors.FindZoneMaps(task.zones or {})
    local list = maps and ns.Sensors.GetActiveWorldQuests(task.factions[1], maps)
    if not list then return "unknown", info end
    info.worldQuests = list
    return (#list > 0) and "todo" or "done", info
  end

  if task.progress then
    info.progress = ns.Sensors.GetObjectiveProgress(task.progress.questId, task.progress.objective)
  end

  local done = false
  if task.questIds and #task.questIds > 0 then done = allDone(task.questIds) end
  if done == true or ns.DB:IsMarked(guide, task) then return "done", info end

  local status, reason = checkRequires(task)
  if status then
    info.reason = reason
    return status, info
  end

  if done == nil then return "unknown", info end
  return "todo", info
end

function State:Evaluate(guide)
  ns.DB:Prune(guide)
  local sources = ns.DB.account.sources
  local result = { guide = guide, entries = {}, byKey = {}, steps = {} }

  for _, task in ipairs(guide.tasks) do
    local status, info = self:TaskStatus(guide, task)
    local entry = {
      task = task,
      status = status,
      info = info,
      enabled = sources[task.source] ~= false,
      skipped = ns.DB:IsSkipped(guide, task),
    }
    result.entries[#result.entries + 1] = entry
    result.byKey[task.key] = entry
  end

  for _, task in ipairs(guide.order) do
    local entry = result.byKey[task.key]
    if entry.enabled and entry.status == "todo" and not entry.skipped then
      result.steps[#result.steps + 1] = entry
    end
  end

  if guide.faction then result.renown = ns.Sensors.GetRenown(guide.faction) end
  return result
end
```

```lua
local _, ns = ...
local L = ns.L

-- Transforme le résultat de State:Evaluate en données prêtes à afficher. Aucune API du jeu ici.
local Models = {}
ns.Models = Models

function Models.TaskTitle(task)
  if task.title then return task.title end
  if type(task.id) == "number" then return L.UNKNOWN_QUEST:format(task.id) end
  return tostring(task.id)
end

function Models.RepText(rep)
  if rep and rep > 0 then return L.REP_FMT:format(rep) end
  return ""
end

function Models.Target(entry)
  local task = entry.task
  if task.type == "worldquests" then
    local wq = entry.info.worldQuests and entry.info.worldQuests[1]
    if wq and wq.map and wq.x and wq.y then return { map = wq.map, x = wq.x, y = wq.y, title = wq.title } end
    return nil
  end
  if task.map and task.x and task.y then
    return { map = task.map, x = task.x, y = task.y, title = Models.TaskTitle(task) }
  end
  return nil
end

function Models.Step(result, viewIndex)
  local m = {}
  local renown = result.renown
  if renown then
    m.renownText = L.RENOWN_FMT:format(renown.level, renown.earned, renown.threshold)
    m.renownValue = renown.earned
    m.renownMax = renown.threshold
  end

  local steps = result.steps
  if #steps == 0 then
    m.empty = true
    m.title = L.NO_STEP
    return m
  end

  local i = math.max(1, math.min(viewIndex or 1, #steps))
  local entry = steps[i]
  m.index, m.count, m.entry = i, #steps, entry
  m.title = Models.TaskTitle(entry.task)
  m.kind = L["TYPE_" .. entry.task.type]

  local detail = {}
  if entry.task.note then detail[#detail + 1] = entry.task.note end
  if entry.info.progress then
    detail[#detail + 1] = L.PROGRESS_FMT:format(entry.info.progress.have, entry.info.progress.need)
  end
  if entry.info.worldQuests then
    for k = 1, math.min(3, #entry.info.worldQuests) do
      local wq = entry.info.worldQuests[k]
      detail[#detail + 1] = wq.title .. " " .. Models.RepText(wq.rep)
    end
  end
  m.detail = table.concat(detail, "\n")
  m.rep = Models.RepText(entry.task.rep)
  if steps[i + 1] then m.nextText = L.NEXT_FMT:format(Models.TaskTitle(steps[i + 1].task)) end
  m.target = Models.Target(entry)
  return m
end

local GROUPS = {
  { type = "weekly", label = "GROUP_WEEKLY" },
  { type = "daily", label = "GROUP_DAILY" },
  { type = "worldquests", label = "GROUP_WORLDQUESTS" },
  { type = "quest", label = "GROUP_SIDEQUESTS" },
  { type = "rare", label = "GROUP_RARES" },
}

function Models.List(result, hideDone)
  local rows = {}
  for _, group in ipairs(GROUPS) do
    local items, remaining = {}, 0
    for _, entry in ipairs(result.entries) do
      if entry.task.type == group.type and entry.enabled then
        if group.type == "worldquests" then
          for _, wq in ipairs(entry.info.worldQuests or {}) do
            remaining = remaining + 1
            items[#items + 1] = {
              kind = "worldquest", status = "todo", text = wq.title, rep = Models.RepText(wq.rep),
              target = (wq.map and wq.x and wq.y) and { map = wq.map, x = wq.x, y = wq.y, title = wq.title } or nil,
            }
          end
        else
          if entry.status ~= "done" then remaining = remaining + 1 end
          if not (hideDone and entry.status == "done") then
            local text = Models.TaskTitle(entry.task)
            if entry.info.progress then
              text = text .. " " .. L.PROGRESS_FMT:format(entry.info.progress.have, entry.info.progress.need)
            end
            items[#items + 1] = {
              kind = "task", entry = entry, status = entry.status, text = text, reason = entry.info.reason,
              rep = Models.RepText(entry.task.rep), target = Models.Target(entry),
            }
          end
        end
      end
    end
    if #items > 0 then
      local label = L[group.label]
      if group.type == "quest" then label = label:format(remaining) end
      rows[#rows + 1] = { kind = "header", text = label }
      for _, item in ipairs(items) do rows[#rows + 1] = item end
    end
  end
  return rows
end
```

```lua
local Navigation = {}

local function tomtomAvailable()
  return type(TomTom) == "table" and type(TomTom.AddWaypoint) == "function"

  if self.tomtomUid and tomtomAvailable() and TomTom.RemoveWaypoint then
    TomTom:RemoveWaypoint(self.tomtomUid)
  end
  self.tomtomUid = nil
  if self.blizzard then
    pcall(C_Map.ClearUserWaypoint)
    self.blizzard = nil
  end
  self.target = nil
end

-- x et y en pourcentage (0 à 100), comme dans les guides.
function Navigation:SetTarget(map, x, y, title)
  self:Clear()
  if not (map and x and y) then return false end
  if self:UseTomTom() then
    self.tomtomUid = TomTom:AddWaypoint(map, x / 100, y / 100, { title = title, from = "Sentier", persistent = false })
  else
    local ok = pcall(function()
      C_Map.SetUserWaypoint(UiMapPoint.CreateFromCoordinates(map, x / 100, y / 100))
      C_SuperTrack.SetSuperTrackedUserWaypoint(true)
    end)
    if not ok then
      ns.Registry:Problem(("Repère impossible sur la carte %d"):format(map))
      return false
    end
    self.blizzard = true
  end
  self.target = { map = map, x = x, y = y, title = title }
  return true
end
```

```lua
local _, ns = ...

-- Mode collecte : note la réputation annoncée par les quêtes, pour remplir les guides.
local Collect = {}
ns.Collect = Collect

function Collect:SetEnabled(on)
  ns.DB.account.collect.enabled = on and true or false
end

function Collect:TrackedFactions()
  local set = {}
  for _, guide in ipairs(ns.Registry:List()) do
    if guide.faction then set[guide.faction] = true end
  end
  return set
end

function Collect:Record(questId, rewards, extra)
  local store = ns.DB.account.collect
  if not store.enabled or not questId or not rewards then return false end

  local tracked = self:TrackedFactions()
  local kept = {}
  for _, r in ipairs(rewards) do
    if tracked[r.factionId] and (r.amount or 0) > 0 then
      kept[#kept + 1] = { factionId = r.factionId, amount = r.amount }
    end
  end
  if #kept == 0 then return false end

  extra = extra or {}
  local pos = (extra.map and extra) or ns.Sensors.GetPlayerPosition() or {}
  store.quests[questId] = {
    title = extra.title,
    worldQuest = extra.worldQuest == true,
    rewards = kept,
    map = pos.map,
    x = pos.x,
    y = pos.y,
    seen = ns.Sensors.Now(),
  }
  return true
end
```

```python
"""Petit client pour l'API web de Blizzard (Game Data)."""
import base64
import json
import os
import time
import urllib.parse
import urllib.request


def load_env(path):
    """Ajoute les variables d'un fichier .env à l'environnement, sans écraser l'existant."""
    if not os.path.exists(path):
        return
    with open(path, encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if not line or line.startswith("#") or "=" not in line:
                continue
            key, value = line.split("=", 1)
            os.environ.setdefault(key.strip(), value.strip().strip('"').strip("'"))


class Client:
    def __init__(self, client_id, client_secret, region="eu", locale="fr_FR"):
        self.client_id = client_id
        self.client_secret = client_secret
        self.region = region
        self.locale = locale
        self._token = None

    @classmethod
    def from_env(cls, env_path):
        load_env(env_path)
        return cls(os.environ["BLIZZARD_CLIENT_ID"], os.environ["BLIZZARD_CLIENT_SECRET"])

    def token(self):
        if self._token is None:
            creds = f"{self.client_id}:{self.client_secret}".encode()
            req = urllib.request.Request(
                "https://oauth.battle.net/token",
                data=b"grant_type=client_credentials",
                headers={"Authorization": "Basic " + base64.b64encode(creds).decode()},
            )
            with urllib.request.urlopen(req, timeout=30) as resp:
                self._token = json.load(resp)["access_token"]
        return self._token

    def get(self, path, attempts=4):
        query = urllib.parse.urlencode({"namespace": f"static-{self.region}", "locale": self.locale})
        url = f"https://{self.region}.api.blizzard.com{path}?{query}"
        for attempt in range(attempts):
            try:
                req = urllib.request.Request(url, headers={"Authorization": f"Bearer {self.token()}"})
                with urllib.request.urlopen(req, timeout=30) as resp:
                    return json.load(resp)
            except Exception:
                if attempt == attempts - 1:
                    raise
                time.sleep(1 + attempt)
```

```python
"""Génère Sentier/Guides/Reputation/Midnight/Catalog.lua depuis l'API Blizzard.

Usage : python3 tools/build_catalog.py   (identifiants lus dans .env)
"""
from concurrent.futures import ThreadPoolExecutor
from pathlib import Path

from blizzard import Client

ROOT = Path(__file__).resolve().parent.parent
OUTPUT = ROOT / "Sentier" / "Guides" / "Reputation" / "Midnight" / "Catalog.lua"

# Zones de quêtes de Midnight dans l'API (relevées le 2026-10-13, build 12.1.0_68914).
MIDNIGHT_AREAS = {
    15355: "Harandar",
    15947: "Zul’Aman",
    15968: "Bois des Chants éternels",
    15969: "Lune-d’Argent",
    16340: "La flèche du Vide",
    16648: "Tempête du Vide",
}


def fetch_catalog(client, areas=MIDNIGHT_AREAS, workers=3):
    catalog = {}
    for area_id in sorted(areas):
        quests = client.get(f"/data/wow/quest/area/{area_id}").get("quests", [])
        ids = [qid for qid in dict.fromkeys(q["id"] for q in quests) if qid not in catalog]
        with ThreadPoolExecutor(workers) as pool:
            details = list(pool.map(lambda qid: client.get(f"/data/wow/quest/{qid}"), ids))
        for detail in details:
            catalog[detail["id"]] = {
                "title": detail.get("title") or "",
                "zone": areas[area_id],
                "area": area_id,
                "min_level": (detail.get("requirements") or {}).get("min_character_level"),
            }
    return catalog


def lua_string(value):
    escaped = value.replace("\\", "\\\\").replace('"', '\\"').replace("\r", "").replace("\n", "\\n")
    return f'"{escaped}"'


def render_lua(catalog):
    lines = [
        "-- Généré par tools/build_catalog.py. Ne pas modifier à la main.",
        "local _, ns = ...",
        "ns.MidnightCatalog = {",
    ]
    for qid in sorted(catalog):
        q = catalog[qid]
        level = q["min_level"] if q["min_level"] is not None else "nil"
        lines.append(
            f'  [{qid}] = {{ title = {lua_string(q["title"])}, zone = {lua_string(q["zone"])}, '
            f'area = {q["area"]}, minLevel = {level} }},'
        )
    lines.append("}")
    return "\n".join(lines) + "\n"


def main():
    catalog = fetch_catalog(Client.from_env(ROOT / ".env"))
    OUTPUT.parent.mkdir(parents=True, exist_ok=True)
    OUTPUT.write_text(render_lua(catalog), encoding="utf-8")
    print(f"{len(catalog)} quêtes écrites dans {OUTPUT.relative_to(ROOT)}")


if __name__ == "__main__":
    main()
```

```python
"""Transforme les données du mode collecte en lignes prêtes à coller dans les guides.

Usage : python3 tools/import_collect.py "<WoW>/_retail_/WTF/Account/<COMPTE>/SavedVariables/Sentier.lua"
"""
import re
import sys
from pathlib import Path

GUIDES_DIR = Path(__file__).resolve().parent.parent / "Sentier" / "Guides" / "Reputation" / "Midnight"

FACTION_FILES = {
    2696: "Amani.lua",
    2699: "Singularity.lua",
    2704: "Harati.lua",
    2710: "SilvermoonCourt.lua",
    2772: "ZuljarraForces.lua",
}

NUMBER = re.compile(r"-?(?:\d+\.?\d*|\.\d+)(?:[eE][-+]?\d+)?")
IDENT = re.compile(r"[A-Za-z_][A-Za-z0-9_]*")
FIELD = re.compile(r"([A-Za-z_][A-Za-z0-9_]*)\s*=(?!=)")
ESCAPES = {"n": "\n", "t": "\t", "r": "\r", '"': '"', "'": "'", "\\": "\\", "\n": "\n"}


class LuaParser:
    """Lit les tables Lua littérales écrites par WoW dans les SavedVariables."""

    def __init__(self, text):
        self.s = text
        self.i = 0

    def skip(self):
        while self.i < len(self.s):
            if self.s[self.i] in " \t\r\n":
                self.i += 1
            elif self.s.startswith("--", self.i):
                end = self.s.find("\n", self.i)
                self.i = len(self.s) if end < 0 else end + 1
            else:
                break

    def expect(self, token):
        self.skip()
        if not self.s.startswith(token, self.i):
            raise ValueError(f"'{token}' attendu à la position {self.i}")
        self.i += len(token)

    def parse_file(self):
        out = {}
        while True:
            self.skip()
            if self.i >= len(self.s):
                return out
            m = IDENT.match(self.s, self.i)
            if not m:
                raise ValueError(f"nom attendu à la position {self.i}")
            self.i = m.end()
            self.expect("=")
            out[m.group()] = self.value()

    def value(self):
        self.skip()
        c = self.s[self.i]
        if c == "{":
            return self.table()
        if c == '"':
            return self.string()
        for word, val in (("true", True), ("false", False), ("nil", None)):
            if self.s.startswith(word, self.i):
                self.i += len(word)
                return val
        m = NUMBER.match(self.s, self.i)
        if not m:
            raise ValueError(f"valeur inattendue à la position {self.i}")
        self.i = m.end()
        text = m.group()
        return float(text) if any(ch in text for ch in ".eE") else int(text)

    def string(self):
        self.i += 1
        out = []
        while True:
            c = self.s[self.i]
            if c == '"':
                self.i += 1
                return "".join(out)
            if c == "\\":
                nxt = self.s[self.i + 1]
                if nxt.isdigit():
                    digits = re.match(r"\d{1,3}", self.s[self.i + 1:]).group()
                    out.append(chr(int(digits)))
                    self.i += 1 + len(digits)
                    continue
                out.append(ESCAPES.get(nxt, nxt))
                self.i += 2
                continue
            out.append(c)
            self.i += 1

    def table(self):
        self.i += 1
        out = {}
        n = 1
        while True:
            self.skip()
            if self.s[self.i] == "}":
                self.i += 1
                return out
            if self.s[self.i] == "[":
                self.i += 1
                key = self.value()
                self.expect("]")
                self.expect("=")
                out[key] = self.value()
            else:
                m = FIELD.match(self.s, self.i)
                if m and m.group(1) not in ("true", "false", "nil"):
                    self.i = m.end()
                    out[m.group(1)] = self.value()
                else:
                    out[n] = self.value()
                    n += 1
            self.skip()
            if self.i < len(self.s) and self.s[self.i] in ",;":
                self.i += 1


def parse_saved_variables(text):
    return LuaParser(text).parse_file()


def as_list(value):
    if isinstance(value, dict):
        return [value[k] for k in sorted(value)]
    return value or []


def known_quest_ids(guides_dir):
    ids = set()
    for path in Path(guides_dir).glob("*.lua"):
        ids.update(int(m) for m in re.findall(r"G:Quest\((\d+)", path.read_text(encoding="utf-8")))
    return ids


def format_line(quest_id, entry, amount):
    parts = [f"rep = {amount}"]
    if entry.get("map") is not None and entry.get("x") is not None and entry.get("y") is not None:
        parts.append(f"map = {int(entry['map'])}, x = {entry['x']:.1f}, y = {entry['y']:.1f}")
    line = f"G:Quest({quest_id}, {{ {', '.join(parts)} }})"
    title = entry.get("title")
    return f"{line} -- {title}" if title else line


def build_suggestions(collected, known):
    result = {}
    for quest_id in sorted(collected):
        entry = collected[quest_id]
        if entry.get("worldQuest") or quest_id in known:
            continue
        for reward in as_list(entry.get("rewards")):
            file = FACTION_FILES.get(int(reward.get("factionId", 0)))
            if file:
                result.setdefault(file, []).append(format_line(quest_id, entry, int(reward["amount"])))
    return result


def main(argv):
    if len(argv) != 2:
        print(__doc__)
        return 1
    data = parse_saved_variables(Path(argv[1]).read_text(encoding="utf-8"))
    collected = ((data.get("SentierDB") or {}).get("collect") or {}).get("quests") or {}
    suggestions = build_suggestions({int(k): v for k, v in collected.items()}, known_quest_ids(GUIDES_DIR))
    if not suggestions:
        print("Rien de nouveau à ajouter.")
        return 0
    for file in sorted(suggestions):
        print(f"\n-- {file}")
        for line in suggestions[file]:
            print(line)
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv))
```

```lua
    if button == "RightButton" and data.kind == "task" then
      local guide = ns.Core.result.guide

      ns.DB:SetMarked(guide, task, not ns.DB:IsMarked(guide, task))
      ns.Core:Refresh()
    elseif data.target then

    GameTooltip:AddLine(data.text)
    if data.reason then GameTooltip:AddLine(data.reason, 1, 0.3, 0.3) end
    if data.entry.task.note then GameTooltip:AddLine(data.entry.task.note, 1, 1, 1, true) end
    GameTooltip:AddLine(L.MANUAL_HINT, 0.6, 0.6, 0.6)
    GameTooltip:Show()
  end

    if p.rows[i] then return p.rows[i] end

    row:SetHeight(ROW_HEIGHT)
    row:RegisterForClicks("LeftButtonUp", "RightButtonUp")
```

```lua
local addonName, ns = ...
local L = ns.L

ns.Core = Core

local REFRESH_EVENTS = {
  "QUEST_TURNED_IN",
  "QUEST_LOG_UPDATE",
  "QUEST_ACCEPTED",
  "QUEST_REMOVED",
  "UPDATE_FACTION",
  "MAJOR_FACTION_RENOWN_LEVEL_CHANGED",
  "MAJOR_FACTION_UNLOCKED",
  "QUEST_DATA_LOAD_RESULT",
  "ZONE_CHANGED_NEW_AREA",
}

function Core:CurrentGuide()
  local guide = ns.Registry:Resolve(ns.DB.char.guide)
  if guide then ns.DB.char.guide = guide.id end
  return guide
end

function Core:SetGuide(id)
  ns.DB.char.guide = id
  self.lastStepKey = nil
  self:Refresh()
end

function Core:CollectWorldQuests(result)
  if not ns.DB.account.collect.enabled or not result.guide.faction then return end
  for _, entry in ipairs(result.entries) do
    for _, wq in ipairs(entry.info.worldQuests or {}) do
      ns.Collect:Record(wq.questId, { { factionId = result.guide.faction, amount = wq.rep } },
        { title = wq.title, worldQuest = true, map = wq.map, x = wq.x, y = wq.y })
    end
  end
end

function Core:Refresh()
  local guide = self:CurrentGuide()
  if not guide then return end
  local result = ns.State:Evaluate(guide)
  self.result = result
  self:CollectWorldQuests(result)

  -- Quand l'étape en cours change, on revient dessus et on déplace le repère.
  local current = result.steps[1]
  local key = current and (guide.id .. ":" .. current.task.key)
  if key ~= self.lastStepKey then
    self.lastStepKey = key
    ns.UI.viewIndex = 1
    local target = current and ns.Models.Target(current)
    if target then ns.Navigation:SetTarget(target.map, target.x, target.y, target.title) end
  end

  ns.UI:Render(result)
end

-- Regroupe les événements rapprochés en un seul recalcul.
function Core:RequestRefresh()
  if self.pending then return end
  self.pending = true
  C_Timer.After(0.5, function()
    self.pending = false
    self:Refresh()
  end)
end

function Core:ScheduleReset()
  local seconds = ns.Sensors.GetSecondsUntilDailyReset()
  if not seconds then return end
  if self.resetTimer then self.resetTimer:Cancel() end
  self.resetTimer = C_Timer.NewTimer(seconds + 5, function()
    self:RequestRefresh()
    self:ScheduleReset()
  end)
end

Core:SetScript("OnEvent", function(self, event, ...)
  if event == "ADDON_LOADED" then
    if ... == addonName then
      ns.DB:Init()
      self:UnregisterEvent("ADDON_LOADED")
    end
  elseif event == "PLAYER_LOGIN" then
    ns.UI:Create()
    if ns.DB.char.hidden then ns.UI.frame:Hide() end
    for _, e in ipairs(REFRESH_EVENTS) do pcall(self.RegisterEvent, self, e) end
    self:Refresh()
    self:ScheduleReset()
  elseif event == "QUEST_DETAIL" then
    if ns.DB.account.collect.enabled then
      ns.Collect:Record(GetQuestID(), ns.Sensors.GetOfferedQuestRepRewards(), { title = GetTitleText() })
    end
  else
    if event == "QUEST_ACCEPTED" and ns.DB.account.collect.enabled then
      local questId = ...
      ns.Collect:Record(questId, ns.Sensors.GetQuestRepRewards(questId), { title = ns.Sensors.GetQuestTitle(questId) })
    end
    self:RequestRefresh()
  end
end)
Core:RegisterEvent("ADDON_LOADED")
Core:RegisterEvent("PLAYER_LOGIN")
Core:RegisterEvent("QUEST_DETAIL")

local function printDebug()
  if #ns.Registry.problems == 0 then
    print(L.DEBUG_NONE)
  else
    print(L.DEBUG_HEADER)
    for _, p in ipairs(ns.Registry.problems) do print("  " .. p) end
  end
  local maps = ns.Sensors.FindZoneMaps(ns.MidnightZones or {})
  local text = (maps and #maps > 0) and table.concat(maps, ", ") or L.DEBUG_NO_MAPS
  print(L.DEBUG_MAPS:format(text))
end

local function countCollected()
  local n = 0
  for _ in pairs(ns.DB.account.collect.quests) do n = n + 1 end
  return n
end

SLASH_SENTIER1 = "/sentier"
SlashCmdList.SENTIER = function(msg)
  local cmd, arg = (msg or ""):lower():match("^(%S*)%s*(.-)$")
  if cmd == "" then
    ns.UI:Toggle()

    ns.Collect:SetEnabled(false)
    print(L.COLLECT_OFF:format(countCollected()))
  else
    print(L.HELP)
  end
end
```

````markdown
# Ajouter du contenu aux guides

1. En jeu, taper `/sentier collect on`.
2. Jouer normalement dans les zones de Midnight : chaque quête proposée ou acceptée qui donne de la réputation à une faction suivie est notée, avec la position. Les quêtes mondiales sont notées aussi, mais restent lues en direct par le guide.
3. Taper `/sentier collect off`, puis `/reload` pour que WoW écrive le fichier de sauvegarde.
4. Lancer `python3 tools/import_collect.py "<WoW>/_retail_/WTF/Account/<COMPTE>/SavedVariables/Sentier.lua"`.
5. Coller les lignes proposées dans le bon fichier de `Sentier/Guides/Reputation/Midnight/`, avant `G:Order`, puis ajouter leurs numéros dans `G:Order` à l'endroit voulu.
6. Ajouter si besoin une note (`note = "..."`) ou un prérequis (`requires = { { renown = 8 } }` ou `requires = { { quest = 12345, title = "Nom" } }`).
7. Lancer `busted`, puis `/reload` en jeu.

Pour un rare ou une activité hebdomadaire, trouver son numéro de quête caché (commentaires Wowhead, ou `/dump C_QuestLog.IsQuestFlaggedCompleted(<numéro>)` avant et après l'avoir fait), puis écrire par exemple :

```lua
G:Rare("rare-nom", { questId = 12345, rep = 75, map = 2437, x = 30.5, y = 22.8 })
G:Weekly("nom-activite", { title = "Nom", questIds = { 12345 }, rep = 1000 })
```

Une activité sans numéro de quête se coche à la main (clic droit dans la liste). Avec `shared = true`, la coche vaut pour tous les guides.
````
